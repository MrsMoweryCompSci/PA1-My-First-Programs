Getting Started 
We are going to use GitHub and Visual Studio Code (VS Code) to complete our Java programming assignments. GitHub will be used to access and save your programming projects, while VS Code is where you will write, run, test, and debug your Java code.

Step 1: Get Your Assignment
Open the assignment posted in Google Classroom and follow the GitHub Classroom link to accept the assignment and create your repository.

Step 2: Open the Project in VS Code
Use the procedures on your GitHub & VS Code Student Cheat Sheet to clone your assignment repository to your computer.  Remember to save your programming assignments in: Documents → AP_CSA_2026 → Labs Once the repository is cloned, open the project folder in VS Code.

Step 3: Complete the Programs
Use VS Code to write, run, test, and debug each program described below.  Read each problem carefully and make sure your program produces the requested output before moving on.

Step 4: Save & Submit Your Work
When you're finished working, follow the submission/sync procedures on your Student Cheat Sheet to save your changes back to GitHub.  Then return to Google Classroom and mark the assignment as complete.

Important: Your work is not considered submitted simply because it runs correctly in VS Code. Make sure your most recent code has been successfully synced to GitHub before leaving the assignment.

Each class is represented with a file in java. The file name must match the class name and have the ".java" extension.


Program #1
Write code to ask the user to enter their name and print the following message:

Hi <name>, welcome to AP CSA!

Where <name> is replaced with the name input by the user.



Program #2
Write a program that asks the user for three names, then prints the names in reverse order.

Sample Run:
Please give me name one: Emmarie
Please give me name two: Diana
Please give me name three: Augustus

Augustus, Diana, Emmarie




Program #3
Your weight is actually the amount of gravitational attraction exerted on you by the earth. You will not weight the same on the other planets, because their gravitational attraction to you is different. Write a program that accepts the user's weight (in pounds) and then prints off how much you would weight on each planet.

A table of planet multipliers are below (for example, Mercury's multiplier is 0.4, meaning if you take your weight times 0.4, you will get your weight on Mercury.

Planet	    Mercury	Venus	Mars	Jupiter	Saturn	Uranus	Neptune
Multiplier	0.4	    0.9	  0.38	2.3	    1.1	   0.92	  1.2



Program #4
Write a program that starts with seconds (provided by the user) and then displays that value converted to full hours, minutes and seconds.

Sample Run:
Give me any amount of seconds: 356442
99 hours, 0 minutes, 42 seconds.
